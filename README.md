# Sound Check

A speech sound planner for speech pathologists: goal setting, session tracking and progress for speech sound disorders, in Australian English.

## What's in it

- **Assess**: Caroline Bowen's Quick Screener (with picture cards), the ICS, an automatic PCC/PVC and process analysis, and a sound profile with PMV and vowel charts.
- **Goals**: age-referenced goal suggestions using McLeod & Crowe (2018) norms and process elimination ages, with traditional, minimal pairs, multiple and maximal opposition approaches.
- **Session**: a built-in word bank with pictures and word shapes, a trial tally, flashcards with stamps and an abacus, kids' practice games, and elicitation strategies with "what works" tracking.
- **Get the sound**: Bowen-based cues (Table 6.5 imagery, verbal and gesture cues), shaping routes, and bridge phrases and chains (e.g. *hot chips*, *s + bin = spin*, *pickle + app = clap*).
- **Progress**: norms comparison, a one-page printable summary, home practice sheets, and a kid-friendly progress view.

## Running it

Open `index.html`. The app saves client data through claude.ai artifact storage, so it saves only when opened as the published Claude artifact. Opened anywhere else, it runs in **preview mode** with an example client, and changes aren't kept.

No client data is stored in this repository.

## Icon

The tongue mascot icon is in `icons/` (`icon-1024.png` for the App Store size, `apple-touch-icon.png` for the iPad home screen, and `icon.svg` and `favicon-32.png` for the browser tab).
